# Governance

Synapse KB is currently maintained by Tiziano Carpentieri. It is an early project,
not a standards organization. The maintainer reviews changes and publishes releases.

Changes to persistent formats, evidence semantics or agent behavior should be
proposed publicly with compatibility and migration implications. Breaking changes
must be called out. During the alpha, interfaces may change without stability guarantees.

The roadmap prioritizes source fidelity, transparent uncertainty and reproducible
evaluation. A broader governance and conformance process should follow actual
independent implementations and contributor participation.
