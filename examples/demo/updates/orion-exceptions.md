# Orion special conditions

## Orion return window exception

Except for custom-engraved equipment, the Orion return window follows the
standard policy. Custom-engraved equipment is not eligible for a change-of-mind
return. A reported defect uses the separate defect assessment process.

## Orion identity prerequisite

Before proceeding with the Orion return window workflow, verify the order
holder's identity. A serial number alone is not sufficient authorization.
